AI Usage and Model Strategy

AI where it matters, deterministic logic where it is safer.

Fast model

  • Signal tagging
  • FAQ answers
  • Analyst chat

Smart model

  • Executive reports
  • AI CFO strategy
  • Recommendation synthesis
  • One strategic LLM call inside CFO orchestration.
  • JSON-mode outputs for structured AI steps.
  • Fallback reports and extractive answers without Groq.
  • Fast frequent tasks, smart high-value tasks.
AI Strategy6 / 11
Hybrid RAG Pipeline

Retrieval designed for sparse, messy SME data.

question -> deterministic query rewrite -> embedding generation -> Pinecone vector retrieval -> Supabase keyword retrieval -> business/source/type/date filters -> rerank: vector + keyword + recency + urgency -> evidence context -> LLM answer/report/recommendation
Hybrid RAG7 / 11
AI CFO Orchestration

Controlled agent workflow with inspectable outputs.

Stages

  • DataQualityAgent
  • MetricAnalystAgent
  • StrategyAgent
  • CriticAgentDeterministic
  • MemoryAgent

Execution

deterministic prep -> one strategic LLM call -> deterministic critic -> recommendations -> memory + graph persistence

Runs are stored in ai_runs, tool_calls, recommendations, and memories, so the AI is explainable.

Orchestration8 / 11
FAQ Widget and Learning Loop

Customer questions become business intelligence.

owner uploads docs -> docs become website_faq_docs signals -> docs are chunked and indexed -> embed script mounts iframe -> visitor asks question -> RAG retrieves FAQ docs only -> answer is generated -> Q&A becomes website_faq_agent signal
